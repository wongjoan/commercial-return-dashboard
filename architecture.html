Where things happen

  • Data enters only through integration (layer 2). The browser never uploads HR, pay or KPI data.
  • Calculations run server-side (layers 4–5), so the formulas and inputs can't be altered in the browser, and pay inputs never reach roles that may not see them.
  • AI is used only in layer 6, on non-sensitive KPI history, and can only propose — a manager decides.
  • Access control is enforced in layer 7 on every request (and, in the target design, again by RLS in layer 3).
  • Sensitive data (salary, pay band, expense claims, individual surveys) is filtered before a response is built; senior managers get only aggregates of 5+ people.
